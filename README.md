A RESTful backend application built using Java and Spring Boot for managing customers and payment transactions.

Technologies:
1. Java
2. Spring Boot
3. Spring Data JPA
4. MySQL/PostgreSQL
5. Maven
6. Git

API endpoints:
1. POST /api/customers
2. GET /api/customers
3. GET /api/customers/{id}
4. POST /api/transactions
5. GET /api/transactions
6. GET /api/transactions/{id}
